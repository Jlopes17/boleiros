# Boleiros

Protótipo web em PT-BR inspirado no estilo manager clássico de futebol, com uma camada moderna de carreira de jogador.

## Como testar

Depois que o GitHub Pages estiver ativado, o jogo deve ficar disponível em:

https://jlopes17.github.io/boleiros/

## Ativar GitHub Pages

1. Abra o repositório no GitHub.
2. Vá em Settings > Pages.
3. Em Source, selecione Deploy from a branch.
4. Escolha branch main e pasta /root.
5. Salve.

## Estado atual

- Interface em português brasileiro.
- Estrutura de jogo próxima a manager clássico: elenco, escalação, táticas, treino, mercado, finanças, competições e editor.
